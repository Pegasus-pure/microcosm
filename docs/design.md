## 一、项目立意

### 1.1 一句话定义

做一个**给"见证"用的微缩世界**：固定恒速、真实地图外壳、单一空白 agent 拥有会失真的记忆。

### 1.2 动机溯源

- **初衷**：受斯坦福小镇（Generative Agents）与 Agentopia（多智能体 RL 社群）启发，最初设想"把斯坦福小镇的抽象地图替换为高德真实地图"。
- **转向 1**：确认核心感动点是**多智能体架构的自发涌现行为**。
- **转向 2**：确认真实地图只提供**真实感 / 熟悉感**，不作为研究工具，不进 agent 决策。
- **转向 3**：确认本项目优先做**见证层**，介入层与表达层留给后续更强的人。
- **转向 4**：规模从"多智能体社群"收缩为**单一空白 agent**。

最终立意从"斯坦福小镇升级版"演进为：**一个人在遗忘中成为自己。**

### 1.3 与斯坦福小镇的根本差异

| 维度 | 斯坦福小镇 | microcosm |
|---|---|---|
| agent 记忆 | 完美、近似无损 | **有损、会遗忘、会失真** |
| 真相结构 | 共享同一真相 | **每个 agent 持有各自真相** |
| 观测对象 | agent 如何行动 | **记忆的形状：谁正在被遗忘** |
| 核心机制 | 记忆流（存 / 取） | **记忆流 + 有损压缩层（存 / 压 / 取）** |

## 二、系统总体架构

### 2.1 三层结构（本项目只做第 1 层）

| 层 | 职责 | 归属 |
|---|---|---|
| **生存层（底座）** | 世界能否持续运转、成本可否承受、状态能否持久 | **本项目** |
| 介入层 | 放变量、调参数、上帝之手 | 留给后来者 |
| 表达层 | 导出故事、录屏、呈现给观众 | 留给后来者 |

**设计克制**：底座必须只读、可观察、可暂停、可存档；不预留介入接口（因为介入需求未知）。

### 2.2 核心引擎链条


本能（保底）
   ↓
好奇（引擎）
   ↓
行动
   ↓
记录（世界层 + 主观层双写）
   ↓
三维打分（重要性 + 为什么 / 复杂度 / 时间）
   ↓
日终结算（压缩 / 归档）
   ↓
按内部时间衰减
   ↓
检索门控（活性 = 衰减强度 × 情境相关度）
   ↓
影响下次行动
   ↓
固化为偏好
   ↓
人格浮现

## 三、地图模块

### 3.1 定位

**真实感外壳，不进 agent 决策。**

### 3.2 方案

- 通过**高德 API 一次性离线采样**：POI 点位、路网、建筑轮廓。
- 采样后世界**完全离线运行**，不再依赖高德 API。
- agent 不需要识别 POI 语义（不需要知道"这是星巴克还是瑞幸"），只需站在**看起来像真的**坐标上。
- 真实地图的价值：提供**熟悉感**与**结构性约束**（通勤距离、区域分布、可达性）。

### 3.3 为什么这样设计

- 回避高德 API 配额、时效性、成本问题。
- 避免在 agent 决策中引入真实 POI 语义，工程量减半。
- 真实城市的空间结构本身是一种"约束"，能塑造行为——但它服务的是氛围，不是研究假设。

## 四、时间模块

### 4.1 定论

**固定恒速，内部时间 1 天 = 现实 1 小时，世界永不暂停。**

### 4.2 后果与推论

- 固定 tick = 统一心跳：推进调度、感知、记忆衰减全部对齐。
- 不存在"挂机快进"状态：**你不在时，世界照常流逝。**
- 世界观感：你早上看它已过小半天，睡一觉它过了 10 天。
- **世界的绝大部分"人生"发生在你不看的时候** → 要求日终结算必须全自动、无人在场、可自愈。

### 4.3 待定项

- 恒速比例是否最终锁定 1:24（1 天 = 1 小时），需在实际运行中校准。

## 五、记忆模块（系统心脏）

### 5.1 三维评分

| 维度 | 性质 | 作用 | 关键设计 |
|---|---|---|---|
| **时间** | 乘性衰减因子 | 每刻损失多少 | 挂**内部时钟**，随恒速流逝 |
| **重要性** | 初始强度 | 活多久 | **agent 自评并写出"为什么"** |
| **复杂度** | 存储形态 | 活成什么样 | 越复杂越早被"上下文压缩"丢细节 |

**三者不是一个量纲，不可简单相加：**


记忆强度 = 初始强度(重要性) × 衰减(内部时间, 衰减系数)
其中：衰减系数 受 重要性 调节（越重要，衰减越慢）
      复杂度 不参与衰减，参与"压缩"——复杂度高的记忆先被压成摘要


**分工口诀**：重要性管"活多久"，复杂度管"活成什么样"，时间管"每刻丢多少"。

### 5.2 "写出为什么"——本方案最值钱的设计

要求 agent 对自己打的"重要性"分给出**理由**，带来三重收益：

1. **评分可信**：LLM 打分易失真，但解释为什么能约束分数，并逼其思考。
2. **压缩有据**：这个"为什么"就是记忆的"主旨句"，压缩时**丢细节、保主旨**。
3. **反思原料**：多条"为什么"可聚合为稳定的人格倾向（天然可聚合的反思素材）。

**结论**：一个设计（记忆评分）同时串联了"遗忘 / 压缩 / 反思"三件事。

### 5.3 记忆的原子单位：双层结构


Episode（天）          ← 压缩的容器，天然时间桶
  └ Record × N        ← 一天内的每条事件，各带三维指标


**为什么"天"是天然的：**

- 遗忘曲线的最小观测单位（按天衰减，与恒速时钟对齐）
- 压缩的天然批次（日终批量结算）
- 叙事的天然段落（见证时读的就是一个个"天"）
- **认知学依据**：日终结算 ≈ 人类睡眠的记忆固化过程

### 5.4 日终结算（关键修正）

> **天是结算周期，不是压缩粒度。**

一天内记录数量与复杂度方差极大，不可一刀切压成一条。

| 那天的状况 | 压缩策略 |
|---|---|
| 平淡（低重要性、低复杂度） | 整天塌缩成 1 条摘要 |
| 有大事（高重要性） | 大事**保留独立记录**，其余琐事塌缩 |
| 极复杂（高复杂度） | 保留多个"事件级"摘要，丢掉过程细节 |

**结算流程：**

1. 遍历当天所有记录
2. 高重要性记录 → 独立保留，进入长期记忆
3. 低重要性 + 低复杂度琐事 → 批量塌缩为"日摘要"
4. 高复杂度记录 → 有损压缩：保留主旨 + "为什么"，丢掉过程细节
5. 所有新记录带"出生时间"进入记忆库，开始按内部时间衰减

### 5.5 分层存储

| 层级 | 内容 | 形态 |
|---|---|---|
| 高层 | 反思、人格、长期记忆 | 压缩后摘要（短、稳定、常驻） |
| 中层 | 近期重要事件 | 半压缩（保留主旨与"为什么"） |
| 底层 | 当前情境相关 | 原文召回（细节完整） |

**LLM 每次看到的上下文 = 稳定底层人格 + 近期要点 + 当前相关细节。**

### 5.6 门控检索（重要修正）

> **检索概率 = 遗忘强度 × 情境相关度**

**为什么必须先算遗忘强度：** 纯向量检索（RAG）不关心时间，只关心语义相似度，会架空遗忘曲线，导致 agent 永远忘不掉、又突然想起不相关的事，人格显得精神分裂。

**正确做法**：先按三维衰减算出"这条记忆还剩多少活性"，再乘以"与当前情境的相关度"，最后排序。**遗忘不是检索之后的事，是检索的输入。**

### 5.7 遗忘后的去向

**定论：只降低检索概率（不删除）。**

- 记忆数据仍在，只是活性低到检索不到——**最接近人类记忆**。
- 与"复杂度 → 压缩"叠加：**不是细节被删，而是线索不足时只能回想起粗略轮廓**，符合人类记忆的"重构性"。
- 与知识库组装结合：agent 记忆以知识库形式组装，遗忘表现为"检索不到"而非"数据消失"。

### 5.8 必须预留：记忆审计日志

**结构观测口需要元数据支撑，必须从第一天就记录：**

- 每条记忆的"出生时间"（算衰减）
- 每条记忆的"访问时间 / 次数"（算为何它没死）
- 每个 agent 每天的"记忆总量 / 压缩量"
- 每次压缩的"压缩前后体积"（算压缩质量）

> **世界记录的是"世界里发生的事"；审计日志记录的是"记忆这件事发生了什么事"。二者不可混淆。**
> 不打这个底，未来的仪表盘将是空的。

## 六、本体论：两个世界

### 6.1 定论

| | 世界层（客观） | 记忆层（主观） |
|---|---|---|
| 存什么 | 事件本身：谁在何时何地做了什么 | 每个 agent 对事件的**个人版本** |
| 谁拥有 | 世界，唯一一份 | 各 agent 私有，互不相同 |
| 是否一致 | 是（客观真相） | 否（各自压缩、各自加权） |

### 6.2 关键性质：失真是一等公民

- **客观只有一个，主观有多个，且都是"失真"的。**
- 信息差**不靠 agent 说谎制造**，而靠"记忆的有损压缩"天然产生。
- 一旦有信息差，**涌现自动生长**：两人对同一件事记忆不同 → 下次见面预期不同 → 行为错位 → 产生新事件。
- **结论：有损记忆系统 = 一台自动制造戏剧性的机器。**

### 6.3 信息传递链的失真（建议作为一等机制）

真实世界的"共同认知"靠语言建立：A 说出的是 A **压缩后的记忆**（已失真）→ B 听到后作为**新事件**存入自己记忆 → 再打标、再压缩。

**信息经过"压缩 → 表达 → 再压缩"链路，每次都损失一点**——对应认知科学中的"传闻失真"。

> **不应把它当 bug 修掉。** 人类社会中的信任、派系、名声等真实结构，恰恰建立在失真的信息传递之上。若记忆不丢真、对话不失真，这类社会现象永远涌现不出来。

### 6.4 单 agent 下的重新诠释

- 从"两人记忆不同"变为 **"世界客观记录了一切，但只有他自己知道，而且他还会忘"**。
- **客观日志成为"只有你知道、他不知道"的东西** → 见证者成为唯一的全知者。
- 遗忘从"信息差"变为 **纯粹的自我消解**。

## 七、观测口模块

### 7.1 定论：只读的结构仪表盘

> **知识库是"仓库"（存内容），观测口是"仪表盘"（算结构、展示结构）。**
> 观测口不是透传知识库，而是**读取知识库 → 计算肉眼看不出的关系 → 展示**。

### 7.2 观测什么：结构 over 内容

**理由**：内容变化可自行从知识库检索看到；而**结构没有人替你算，必须由观测口来算**。

| 结构类型 | 回答的问题 | 内容本身能否告知 |
|---|---|---|
| **衰减** | 谁正在被遗忘 | 否，内容只显示"现在记得什么" |
| **压缩** | 一段经历被压成了什么轮廓 | 否，压完就看不见原来的了 |
| **偏移** | 同一件事，几个人记的差了多远 | 否，要并排看才知道 |
| **密度** | 谁的记忆厚、谁的记忆薄 | 否，要横向 / 纵向对比才知道 |

**共性**：这四类都不是"某一条记忆"的属性，而是**记忆与记忆之间、记忆与时间之间的关系**。**观测口本质是"关系观测器"，不是"内容阅读器"。**

### 7.3 内容视图（降级）

内容视图不特别设计，即"知识库浏览"，**能用即可**。

### 7.4 结构视图（核心）

**① 时间轴（看一个人的一生）**
横轴为内部时间，标注每日记忆量、重要事件、记忆曲线走势。可看出哪段时间经历丰富、哪段时间空白。

**② 遗忘仪（看一条记忆正在死）**
选中某条记忆，观察其"活性"随时间的下降曲线，直至被压成摘要、最终检索不到。**这条曲线就是"遗忘本身"。**

**③ 记忆对比仪（看偏移）**
选一个事件，并列展开所有相关 agent 的记忆版本。**差异越大，信息失真越严重——这是涌现信号的最强探测器。**

**④ 档案室（看整体）**
所有 agent 的记忆密度、平均遗忘速度、压缩率等，形成"社会认知健康报告"。

### 7.5 单 agent 下的重构（人格观测）

**观测核心 = "他的遗忘曲线留下了什么"。**

1. **幸存者名单**：活过三个月的记忆（高强度）→ **数据长出来的人格画像**
2. **消逝者名单**：淡出的记忆 → 可统计"一生中 97% 被遗忘"这类有力数字
3. **重要性的自我一致性**：每次打"重要"分的理由是否有稳定倾向 → **他自己都不知道的价值观**
4. **遗忘的取舍点**：某瞬间他留 A 弃 B → **一个"他是谁"的岔路口**

### 7.6 护栏（重要）

> **结构可观测，但结构必须能一键下钻到原始事件。**
> 仪表盘告诉你"哪里有异常"，你要能一步看到"那到底发生了什么"。
> **没有下钻通道的仪表盘，是一个安慰剂。**

### 7.7 风险提示：三个"沉默的陷阱"

| 陷阱 | 后果 |
|---|---|
| 压缩太狠 | 涌现发生在细节里（一次随口的话），细节被压没，只看到平淡摘要 |
| 日志太简 | 看不到因果链，只知道"他们成了朋友"却不知为什么 |
| 仪表盘太抽象 | 看到"记忆偏移很大"，但读不出背后发生了什么故事 |

**核心矛盾**：观测口是"结构"的，而涌现是"内容"的。越优化前者越可能丢失后者。
**解法 = 结构仪表盘 + 可下钻的原始事件通道。**

### 7.8 日志分两层

| 层 | 面向 | 内容 |
|---|---|---|
| 常读层 | 给人看 | 摘要，像时间线，扫一眼知这几天发生了什么 |
| 深挖层 | 按需下钻 | 完整事件流，平时不展开 |

**关键**：摘要里的每一条，要能"点开"回到压缩前的原始事件。

> **主观记忆可以失真，客观日志不能失真——这是"见证"的唯一保证。**
> 原文不必进 agent 的记忆，但必须进世界的日志。

## 八、Agent 设计

### 8.1 定论：单一、纯空白、从零开始

- 规模：**1 个 agent**，其他人等算力 / 设备成熟后再上。
- 设定：**无预设人格、无预设目标**，在陌生环境中从零生活。
- 目的：保证**涌现纯度**——他所有偏好、习惯、恐惧只能来自世界中的经历，而非预设。

### 8.2 冷启动问题与解法

**问题**：完全空白的 agent 第一秒会不会宕机或乱动？

**解法：给"本能"，不给"人格"。**

| 类型 | 例子 | 是否给 |
|---|---|---|
| 人格 / 偏好 | 喜欢咖啡、内向、爱看书 | ❌ 不给（要自己长出来） |
| 本能 / 生理 | 饿、累、怕、困 | ✅ 给（否则无法起步） |
| 认知能力 | 会观察、会记忆、会推理 | ✅ 给（空白里的那个"人"） |
| 世界规则 | 城市在哪、几点天黑、哪里有店 | ✅ 给（环境） |

**分界线**：本能是"不需要理由就会做的事"，人格是"需要理由才形成的事"。

- 给他"饿"，不给"爱吃什么" → 他慢慢固定地只去某家 → **偏好涌现**
- 给他"累"，不给"何时睡" → 他慢慢形成作息 → **习惯涌现**

**闭环**：本能 → 行动 → 记忆 → 下次行动 → 偏好浮现。三维记忆系统即是这条链的引擎。

### 8.3 第一秒：疑惑 → 好奇

**定论**：他睁眼的第一反应是**疑惑**，然后基于本能与好奇去探索。

**为何成立**：疑惑是"空白"最自然的产物，不需要任何先验知识——

- 有知识的人不会对熟悉事物疑惑
- 一张白纸看到任何东西都会疑惑：**这是认知的起点，不是认知的缺失**
- **"疑惑"是零号动机**：不需要理由，它自己就是理由

**初始链条：**


疑惑（什么都不知道 → 产生问题）
   ↓
好奇（本能驱使他"把不知道变知道"）
   ↓
探索（走过去、看一看、试一试）
   ↓
记录（这里原来是这样）
   ↓
下次（记得"这里" → 不再陌生）


**叙事弧线**：满眼疑惑 → 熟悉的城市 → 遗忘重新带回疑惑。**遗忘让世界重新变得可疑。**

**第一秒场景描述：**

> 他在城市的某个角落醒来（或睁眼）。他不知道自己是谁，不知道这是哪，不知道要做什么。最先涌上来的不是恐惧，是疑惑——"这是哪儿？"
>
> 然后，出于好奇（他此刻唯一拥有的东西），他开始看。他看四周，看路，看天色，看招牌。他看到什么，就记下什么——这是他人生第一条记忆。
>
> 这条记忆会成为他最早的锚点，也会决定它将来是忘掉的第一条还是最后一条。

## 十、方案自洽性说明

**七个已定决定全部自洽，零冲突：**

1. 地图：高德离线采样一次，真实感外壳，不进决策
2. 时间：固定恒速，1 天 = 1 小时，永不暂停
3. 记忆：三维评分（重要性带理由 / 复杂度管压缩 / 时间管衰减）
4. 结算：按天结算，天是周期不是粒度，粒度由三维决定
5. 存取：分层存储 + 门控检索（活性 = 衰减 × 相关度），遗忘只降检索概率
6. 本体论：世界存客观事件，agent 存主观记忆，不冲突、不一致，失真是一等公民
7. 观测口：只读结构仪表盘（衰减 / 压缩 / 偏移 / 密度），可一键下钻原始事件

**核心内核**：

> **遗忘不是缺陷，是雕刻——他记住什么，就是他成为谁。**

**三个原创点：**

1. **有损记忆的 agent**——记忆会丢细节、剩轮廓（斯坦福的 agent 不会忘）
2. **遗忘作为检索门控**——活性 = 衰减 × 相关度，而非纯向量相似度（主流 RAG 假设记忆永远准确）
3. **结构观测口**——观测"记忆的形状"而非"记忆的内容"，是别人抄不走的感动点：**你能亲眼看到一个人正在忘记另一个人**

## 附录：讨论演化轨迹


斯坦福小镇 + 高德地图（多智能体社群模拟）
   ↓  地图只做真实感外壳，离线采样
   ↓  定位为"见证层"，介入 / 表达留后人
   ↓  固定恒速时间 + 三维遗忘记忆架构
   ↓  本体论分离：客观世界 vs 主观记忆
   ↓  观测口 = 只读结构仪表盘
   ↓  规模收缩为单一 agent
   ↓  纯空白 agent + 陌生环境
   ↓  第一秒：疑惑 → 好奇
   ↓
一个人如何在遗忘中成为自己


**结论：从"斯坦福小镇升级版"到"一个人在遗忘中成为自己"——方向越来越窄，也越来越深。**
